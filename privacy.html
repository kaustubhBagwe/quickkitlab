Privacy policy

Read the QuickKitLab privacy overview for local browser processing, contact forms and third-party libraries.

Privacy overview

This starter project does not include user accounts, an application database or a file-upload backend. Tools designed for local processing use browser APIs to work with files on the visitor’s device. Do not claim that every operation is offline: some pages load JavaScript libraries from third-party CDNs.

Contact forms

The contact and report forms use a mailto link to open the visitor’s configured email application. The website itself does not transmit or store form submissions. Replace the placeholder email address before publishing.

Hosting, analytics and advertising

Your hosting provider may collect standard server logs. If you later add analytics, advertising, cookies or third-party services, update this policy to describe the actual services, data collection and user choices before deployment.

Children and sensitive information

Do not submit sensitive personal information or confidential documents through feedback forms. This project is not designed to collect information from children.

Policy updates

Update this page to reflect the actual hosting provider, analytics, advertising partners and applicable legal requirements before making the website public.
